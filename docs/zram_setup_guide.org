#+TITLE: Debian zRAM & Swap Optimization Guide #+AUTHOR: System Administration Notes #+OPTIONS: toc:2 num:t

Overview

Configure zRAM on Debian for low-memory systems (e.g., 4 GB RAM running XFCE).

zRAM creates a compressed block device in RAM and uses it as swap, reducing disk I/O and improving responsiveness under memory pressure.

This guide uses =systemd-zram-generator= instead of the archived =zram-tools= project.

Prerequisites
Debian 12 (Bookworm) or newer
Root or =sudo= privileges
systemd-based system

Install the required packages:

#+BEGIN_SRC bash sudo apt update sudo apt install systemd-zram-generator util-linux #+END_SRC

Step 1: Configure zRAM

Create the configuration file:

#+BEGIN_SRC bash sudo nano /etc/systemd/zram-generator.conf #+END_SRC

Add:

#+BEGIN_SRC ini [zram0]

Use 100% of physical RAM as the maximum zRAM size

zram-size = ram

Compression algorithm

compression-algorithm = zstd

Give zRAM higher priority than disk swap

swap-priority = 100 #+END_SRC

** Notes

=zram-size = ram= sets the logical zRAM capacity to the size of physical RAM. It does not reserve that amount of RAM upfront.
=zstd= provides a good compression ratio, at the cost of some CPU usage.
Higher swap priority means the kernel prefers zRAM over lower-priority swap devices.
Step 2: Configure Disk Swap

Check existing swap devices:

#+BEGIN_SRC bash sudo swapon --show #+END_SRC

** Option A: Keep Disk Swap as a Fallback (Recommended)

Retain disk swap but assign it a lower priority than zRAM.

For a swap file, edit =/etc/fstab=:

#+BEGIN_SRC fstab /swapfile none swap defaults,pri=5 0 0 #+END_SRC

For a swap partition, add =pri=5= to its existing swap options.

** Option B: Disable Disk Swap

If you prefer using zRAM exclusively:

#+BEGIN_SRC bash sudo swapoff -a #+END_SRC

Comment out existing swap entries in =/etc/fstab= to prevent them from activating at boot.

Step 3: Tune Kernel Memory Management

Create a sysctl configuration file:

#+BEGIN_SRC bash sudo nano /etc/sysctl.d/99-zram.conf #+END_SRC

Add:

#+BEGIN_SRC ini

Prefer compressed RAM swap under memory pressure

vm.swappiness = 100

Retain filesystem caches longer

vm.vfs_cache_pressure = 50

Disable swap read-ahead for zRAM

vm.page-cluster = 0 #+END_SRC

Apply the settings:

#+BEGIN_SRC bash sudo sysctl --system #+END_SRC

Step 4: Activate zRAM

Reload systemd and start the generated swap device:

#+BEGIN_SRC bash sudo systemctl daemon-reload sudo systemctl start dev-zram0.swap #+END_SRC

The generator automatically creates and activates the device during subsequent boots. No separate service needs enabling.

Step 5: Verify Configuration

** Check Active Swap

#+BEGIN_SRC bash sudo swapon --show #+END_SRC

Expected configuration:

=/dev/zram0= with priority 100
Disk swap, if retained, with priority 5

** Check Compression Statistics

#+BEGIN_SRC bash sudo zramctl #+END_SRC

Useful columns:

=DISKSIZE=: Logical zRAM capacity
=DATA=: Uncompressed data size
=COMPR=: Compressed data size
=TOTAL=: Actual memory consumed

** Check Memory Usage

#+BEGIN_SRC bash free -h #+END_SRC

Final Notes
zRAM capacity is a maximum logical size, not preallocated physical memory.
Keeping disk swap as a low-priority fallback is generally safer than disabling it entirely.
Monitor CPU usage when using =zstd= on older processors.
A swap priority of 100 ensures zRAM is preferred over disk swap at priority 5.
Adjust zRAM size and compression algorithm according to workload and available CPU resources.
